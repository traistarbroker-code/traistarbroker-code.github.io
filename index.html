Documents, reconciliation
and declaration preparation.

TRAISTAR BROKER is a Windows application used by TRAISTAR BROKER SRL to prepare and review customs dossiers and ASYCUDAWorld XML drafts.

What the application does

It copies source packages into a working dossier, extracts PDF and Excel data, uses OCR for scans, highlights differences with references to source pages and cells, and proposes product analogues from previously accepted declarations. Calculations, identifiers and state updates are performed by application code.

Russian is the main interface language. Product descriptions can be reviewed in Romanian. The application does not submit or release declarations in ASYCUDAWorld.

Why it connects to Google

  • Gmail read access: find the original document thread and verify invoice/AWB references and attachment checksums.
  • Gmail send access: reply with the final, checked PDF to participants of the established source thread when operational sending is enabled and authorized.
  • Google Sheets access: read and synchronize the existing dossier and declaration registry, avoiding duplicates and protecting formulas.

Permissions are requested through Google OAuth. A Google password is never collected by this application. Tokens are encrypted using Windows DPAPI for the local Windows user.

Optional AI extraction

Selected document text can be sent to the OpenAI API after explicit selection and consent. AI results are proposals with source quotations. No mailbox or archive is automatically uploaded to AI, and AI is not given tools to send messages or change files.

This website provides application information and policies. It does not provide access to dossiers, Gmail or the customs registry.
